# Lunar Tweaks

Windows gaming tweaks you can see, check and undo. For Windows 10 and 11 (64-bit).

**Download and info: [lunartweaks.netlify.app](https://lunartweaks.netlify.app)**

This repository only hosts the installer. Get the newest version from [Releases](../../releases/latest), or use the Download button on the website.

- Every change is explained, verified after applying, and can be undone from the Restore Center.
- No telemetry, no account, no RAM or registry "cleaners".
- Free plan included. Pro and Elite are available on the [pricing page](https://lunartweaks.netlify.app/pricing.html).

The installer isn't code-signed yet, so Windows SmartScreen may show "Windows protected your PC" the first time. Click **More info**, then **Run anyway**. Each release lists the installer's SHA-256 checksum if you want to verify the file.

Help: [support page](https://lunartweaks.netlify.app/support.html) or officiallunartweaks@gmail.com
